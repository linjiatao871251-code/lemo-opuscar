# 1920 年代静音影片 — 我们的示范

众多例子中的一个。请勿重复使用其故事、弧线、镜头、道具或时间安排。

示范：*失控的面包* (54.2 s) · `silent-film.mp4` · 来源在 [`demo/`](demo/)


一部时长 40 至 60 秒的单卷喜剧：面包师完美的圆面包逃脱，最后遇到了一个饥饿的女孩。它最依赖的参考资料：基顿的锁链堵嘴和劳埃德的险些失手； 配乐遵循照片播放提示表（Maestoso / Andante / Hurry / Misterioso / Agitato / Tenderly）。

<a id="story--structure"></a>
## 故事与结构

一部单卷短片喜剧，看起来是“投影”的：画面是剧院窗帘之间大门上的 4:3 印刷品；该图像是一幅水墨画，带有水洗灰色和阴影线，印刷在银纸上，边缘闪烁、编织、划痕和烧伤。没有人说话。故事节拍由 **广角镜头动作** 和 **字幕卡** 讲述。唯一的声音是电影钢琴（以及展位中的投影仪）。

喜剧引擎是基顿的：一个普通人，有一个小目标，一个行为不端的物理世界，一张没有反应的脸——以及一个由观众在单一画面中观看的因果链构成的笑点。

示范如何使用表现媒介：

|原生电源|故事运用|
|---|---|
|**锁定广角镜头**|机械笑点：A触发B，B离开画面，观众等待，B回来打C。等待就是个笑话。|
|**字幕**|三到五张卡片包含了动作所不能的内容：前提转折（“面包有其他计划。”），一声喊叫（“停止那个面包师！”），一行对话（“这是你的吗，先生？”）。每张卡片都保留几个单词。|
|**投影速度**|降低追逐速度（以 18 fps、1.3 倍速度、更快的闪烁采样运动）；返回到 16 fps 并为柔和的场景提供更平静的打印效果。速度是一种情感。|
|**虹膜**|打开故事的对象，关闭最后的一瞥。中途停止的虹膜可以让角色看着观众（眨眼）。|
|**随着心情变老**|当出现问题时，损坏会更大，当影片变软时，棕褐色会更温暖，打印会更干净。|

**故事形状（在示范中得到证明）：**骄傲（面包师将他完美的圆形面包高高举起）→物体逃脱（它在窗台上摇摇晃晃，从山上滚下来——一个“圆形”面包，所以它真的可以滚动）→一次差点错过的追逐（他抓住了，它跳了过去）他的手，他凝视着空空的拳头）→一次拍摄中的链式堵嘴（拉锯→一个瓜飞出画面→警员走进去→瓜落在他的头盔上）→它停在一个更需要它的人（一个饥饿的女孩）的脚下→沉默→一个小动作（他把面包分成两半）→回声（她像他一样将她举起半高）→虹膜在她眨眼时关闭。 **剪切而不是添加**：带有电车、雾追逐、屋顶悬挂和八步市场链的早期版本在缩略图中无法读取。一根清晰的链条胜过三根繁忙的链条。

适应任何主题：找到逃脱的物体，最终应该和它在一起的人，可以在一个宽框架中发生的一条机械链，以及一个可以在最后重复并具有新含义的手势。

<a id="shots"></a>
## 镜头

|打|摄影机|
|---|---|
|开幕|当投影仪旋转时，窗帘在黑暗的屏幕上分开；标题卡； **iris 在提起的面包上打开**。|
|设置|锁定的完整镜头：整个前提（骄傲→门槛→滚动→双重拍摄）在一帧中播放。|
|追赶|**追踪镜头**：城镇以0.8滚动，灯柱以1.35从前方掠过，英雄和物体留在画面中。|
|锁链堵嘴（签名）|锁定的极宽，**无切割**：拉锯→瓜从框架顶部出来→2.5秒的等待→警察走进并停在他的目标上→瓜落地。|
|气息|锁定完整的镜头，然后真正的沉默。|
|投标|缓慢的 **推入** 受到激励：当英雄跪下时，摄影机下降到孩子的高度（缩放 1.6 → 2.1）。|
|结束|**iris 将** 关闭在孩子身上，停止，她向观众眨眼，然后关闭； “结束”；窗帘关闭。|

- **手摇采样**：角色和摄影机运动以16 fps采样（追逐中为18）；打印的闪烁、编织、颗粒和划痕会改变每个输出帧 (24 fps)。这种混合使它看起来像是投影的，而不仅仅是低帧率。
- **面无表情的表演**：英雄的脸几乎没有变化；身体在表演——在举重前蹲下，举重保持骄傲，双镜头的两帧快照加上一点跳跃，弯曲和挥击，在跑步时看着空拳头，双手放在膝盖上，跪下。
- **物体也会行动**：面包在走之前会在窗台上摇晃，在错误的时刻跳过鹅卵石，随着音乐减速（ritardando）和岩石，靠在鞋子上。
- **将手臂抬离脸部。** 在此骨骼绑定结构上，向前弯曲将抬起的手臂穿过脸部；通过绑架（侧向、跳跃式）举起庆祝手臂，或者首先将角色转向摄影机。

<a id="score-structure"></a>
## 配乐结构

- **没有拟音，没有声音。**钢琴*是*声音设计，就像在1920年代的电影院中一样：摇摆时紧张的颤音，下降时的下降滑奏，弹跳时的低“嗡嗡声”，双音时的减弱的斯福赞多，高刺和向上运行时的跳跃抓住，“叮……砰”代表空拳头，前臂集群代表拉锯，向上的滑奏代表甜瓜，膨胀减弱的颤音代表等待，下降的滑奏变成急速和弦代表着陆，面包破裂时清脆的小二度，眨眼的装饰音。
- **配乐**：一段时期的原创照片播放音乐**立式钢琴**（VSCO 2 CE，CC0），左手跨步，跟随提示表：Maestoso标题→行板“面包主题”（F大调）→漫画“uh-oh”+加速跑→快点（小调，16分音符运行，144 BPM）→停止时间悬念+ Misterioso步行→Agitato颤音→ritardando（88）→沉默→**簧风琴**（FreePats手风琴，CC0）进入pp→Tenderly（72 BPM的Loaf主题）→结局。主题一开始是骄傲的，结尾是温柔的。
- **投影机的氛围是**：幕布前有灯发出咔嗒声，电机开始旋转，卷轴下发出柔和的爪子和电机的咕噜声，作为寂静中“唯一”的声音向前推进，最后影片的尾巴在收纸卷轴上拍打。
- **段落**：（1）链条堵嘴的停止时间，而瓜出框（只有微弱的颤音膨胀）； (2) 面包停下来，投影仪独自呆了两秒钟——下一个声音是簧风琴。
- 在响度归一化 (−14 LUFS) 之前通过轻微压缩来抑制钢琴的音锤瞬变。将谷物放入图片中；多路复用器颗粒 1.

<a id="palette--props"></a>
## 调色板和道具

- **房屋风格 = 色调绘画 + 重绘。**场景仅以灰度值绘制（打印密度：墨水 0.07、深色布料 0.15–0.3、中木 0.45–0.6、皮肤 0.8、衬衫和围裙 0.9–0.95），具有柔和的光线渐变和细分隔线。然后，**重画** 通道 (WebGL2) 为整个帧上墨：每个边缘暗侧的高斯差轮廓、将亮度海报化为五个柔和的水彩晕染步长以及黑暗中的 45° 阴影线（然后交叉），每两帧重新绘制一次，就像手工重绘动画一样。真实视频帧经历相同的过程（“重绘模式”，请参阅 `stills/frame_redraw.jpg`），因此素材和绘图共用一只手。
- **打印** (`FilmPost`)：银色色调，0.10–0.36 棕褐色，打印黑色 0.055/白色 0.93，S 曲线，高光上有光晕，密度不均匀，闪烁，偶尔有穿孔跳跃的门纹，破损的垂直划痕（白色 = 刮掉乳剂，深色 = 表面有污垢）负片），棕色烧伤从边缘蔓延，小插图，两个八度的银粒。然后`damage()`添加灰尘、门内的毛发和罕见的斑点。
- **框架**：1440×1080位于1920×1080的中心，圆形22像素光圈，带有柔和的深色边缘；两侧是剧院——天鹅绒窗帘被屏幕的溢出物和脚灯照亮。窗帘在开始时分开，在结束时关闭。
- **角色**：2.5D 骨骼绑定结构上逼真的7.5头成人和5头儿童（3D解算关节，偏航投影），默片时代化妆（苍白的皮肤，深色的眼睑和嘴唇）。 示范英雄的剪影标志：褶皱面包帽、白色衬衫外罩深色马甲、白色长围裙。
  英雄的角色设定表，以灰度值作为打印浓度，四种表情和关键姿势：[`demo/stills/modelsheet_v2.jpg`](demo/stills/modelsheet_v2.jpg)。温柔的一幕风格定帧通过完整的制作流程（重画、棕褐色、虹膜、剧院）：[`demo/stills/frame_v2_tender.jpg`](demo/stills/frame_v2_tender.jpg).
- **字幕**：一张带有装饰边框的黑色彩绘卡片，其装饰跟随情感——一条沉重的规则用于喊叫（文字颤抖），带有阶梯角和扇子的双重规则用于叙述，藤蔓和小花表示温柔。 Playfair Display SC 用于标题和喊叫，Old Standard TT Italic 用于旁白和对话。
  四种并排的卡片类型：[`demo/stills/frame_cards.jpg`](demo/stills/frame_cards.jpg)。

## 标题、字幕和片尾卡

- 字幕*是*字幕； `.srt` 列出了它们的文本。每张卡可容纳 2.5–3.75 秒。
- 标题：失控的面包 /*一卷照片剧*。
- 片尾卡（招标边框）：The End · 标题和风格名称 · LEMO-OPUSCAR · LemoLab × Claude Opus 5.5 · 资产积分；窗帘拉上了它。 LemoLab 签核仅属于该风格库的示范：用​​户的影片不带有 LemoLab 积分，也没有该卡的副本。

<a id="pitfalls-we-hit-demo-record"></a>
## 我们遇到的陷阱（示范记录）

- **木偶手臂**（第一次切割）：每条手臂都是一个单独的管子，其完整轮廓覆盖在衬衫上，肩部枢轴从未移动，并且在屈曲后应用外展 - 因此“展开”的头顶手臂实际上向内摆动，升力变成了X。`engine/figure.js`中的修复：先外展，然后屈曲；随着手臂的上升（锁骨），肩关节上升并向前摆动；躯干的肩角在凸起的一侧变细；手臂具有三角肌和 biceps/forearm 轮廓；手臂的轮廓隐藏在靠近肩膀的躯干上方。
- **摆出流行姿势**：在`if`分支中切换姿势会使人物跳跃。每个角色都由关键帧列表（`shots.js` 中的 `poseAt`、`numAt`）驱动，因此姿势、位置和面向始终是缓和的；只有故意的插科打诨（双重镜头）。
- **浮动道具**：在所有漂浮物顶部绘制的手的平均位置“保持”的道具。将其握在手掌之间，位于两臂之间的深度 (`props.between`)，调整其大小以适应手掌之间的间隙，然后通过在给予者和接收者的手掌位置之间进行插值来将其移交 (`palmsAt`)。长面包不能沿其长度滚动 - 使用圆形面包，并将其旋转与距离联系起来（角度=距离/半径）。

- **太多的内容会杀死沉默的人影片.** 每个头 64 像素的八步链式笑点在缩略图中是噪音；第一个版本从未到达第一次审查。一条链子，中间有一个停顿，读着。
- 骨骼绑定结构的脸部看起来就像大特写中的人体模型：保持广角，表现媒介镜头（无论如何这是基顿的语法）并将唯一的特写镜头保留在虹膜内。
- 一只举起的手臂横过女孩的脸，并隐藏了眨眼：将她转向摄影机并通过绑架举起手臂。
- 眉角随面朝方向翻转：“担心”（眉毛内侧向上）对于面朝左边的女孩来说，读作生气；检查最终大小的裁剪中的表达式。
- 摄影机缩放后，虹膜中心必须在 *影片* 坐标中跟踪面部（`girlFace()` 映射世界 → 影片）。
- 在追逐中，英雄首先从未到达面包的手臂范围内，因此抓取没有读取：将手准确地放在物体所在的位置，向下弯曲身体，使跳跃变大（210像素）。
- 仅由暗屏幕照亮的关闭的窗帘是纯黑色的（黑色检测）：添加脚灯。
- 重粒度会产生大文件（CRF 19 时为 170 MB）；使用 `-tune grain -crf 25` (≈ 77 MB) 重新编码。

## 构建笔记

```

  chars.js poses.js sets.js   the cast, key poses, town set pieces
  shots.js       one function per section: bakery · chase · market · roll · sil · tender · irisShot (tonal paintings)
  film.js        assembly: shot → Redraw → iris → FilmPost → gate + curtains; per-section look (damage, sepia, sampling fps, crank)
  cardspecs.js   the intertitles        frames.js   model sheet, card sheet, redraw sample, one-colour example
  sheets.js      rig check scenes, not in the film: ?scene=sheets.test (turnaround + run pose) · heads · redrawFig · armTest · loafTest
  stage.js       the small scene → FilmPost → gate helper that sheets.js draws through
  music/score.py  photoplay score from timeline.json      mix.py   score + projector
  tools/         cuecheck.py · subs.py · dump_timeline.mjs
```
1. 首先写提示表（`timeline.js`）：部分、速度和每个搞笑节拍作为命名热门。 配乐是从同一文件生成的，因此每次命中都会落地（0 毫秒）。
2. 将每个镜头涂成灰色（`?scene=` 剧照供查看），然后通过整个制作流程进行查看 - 重绘通道会更改读取的内容。
3. `sh demo/build.sh`：时间轴 → 配乐 → 提示检查 → 混合 → srt → 渲染（约 55 秒，2 个工作人员处理 1301 帧）→ 复用器 (−14 LUFS) → 颗粒重新编码 → 静止图像。约2.5分钟。
4. 每秒查看 1 帧，然后以 0.1–0.2 秒的速度对每个片段进行帧条带。

<a id="engine-reference"></a>
## 发动机参考

四个模块，可单独使用：

|模块|主要API|
|---|---|
|`engine/ink.js`（色调图）|`setFrame(t, {boil})` · `form(g, pts, {v, line, grad, shade, cyl})`（灰度值 `v` 的填充、阴影、轮廓形状） · `stroke(g, pts, w)` · `drawShape(g, shape, style)`（**任何这种风格的路径**； `style.color` 以供颜色掩模使用的色调绘制）·`sparkPts(cx, cy, r, tail)`·`catmull`、`ellipsePts`、`rectPts`、`mottle`、`shade`、`grey(v)`|
|`engine/redraw.js`|`new Redraw(w, h).render(canvasOrImageOrVideo, {frame, lines, tone, hatch, levels, gap, sigma, p, eps, phi, bilateral, src})` → 画布。将色调绘画*或真实的视频帧*转换为墨水绘图（重绘模式：照片的`bilateral: 3, p: 34, eps: .24`）。|
|`engine/film.js`|`new FilmPost(w, h).render(src, {frame, strength, sepia, crank, grain, flicker, weave, scratches, burn, vignette, halation, exposure, jump}, colorMask?)` → 帆布·`damage(g, x, y, w, h, frame, strength)`（灰尘、毛发、斑点）。将其堆叠在 **任何** 2D 画布上。|
| `engine/cards.js` | `intertitle(g, W, H, {level, lines:[{text, font, size, italic, weight, spacing}], shake}, t)` · `decoBorder(g, x, y, w, h, level)` · `iris(g, W, H, cx, cy, r)` · `theatre(g, W, H, gate, spill, curtainOpen)` |
|`engine/figure.js` + `heads.js`|`drawFigure(g, character, {x, ground, scale, yaw, pose, t, props})` · `P0()`、`mixPose`、`runPose(ph)`、`walkPose(ph)`、`runBob` · `chars.js` 中的角色，`poses.js` 中的姿势|

**一种颜色。** 打印为单色；要使一个元素保持其自己的色调，请将其绘制到单独的蒙版画布（颜色 + Alpha）中，并将其传递给 `FilmPost.render`：它保留蒙版具有 Alpha 的色调，但仍然会出现颗粒、闪烁和晕影。

```js
import { drawShape, sparkPts, grey, setFrame } from './engine/ink.js';
import { Redraw } from './engine/redraw.js';
import { FilmPost, damage } from './engine/film.js';

setFrame(t);
const W = 1440, H = 1080, mk = () => Object.assign(document.createElement('canvas'), { width: W, height: H });
const frame = mk(), f = frame.getContext('2d'), mask = mk(), m = mask.getContext('2d');
f.fillStyle = grey(.9); f.fillRect(0, 0, W, H);
const sp = sparkPts(720, 460, 220, 260);                 // a four-point light with a short tail
drawShape(f, sp.star, { v: .6, shade: 12 });            // tonal version (gets inked + hatched)
drawShape(f, { pts: sp.tail, closed: false }, { line: 10 });
drawShape(m, sp.star, { color: '#D97757' });            // the one colour
const inked = new Redraw(W, H).render(frame, { frame: Math.round(t * 24) });
const print = new FilmPost(W, H).render(inked, { frame: Math.round(t * 24), strength: .6, sepia: .15 }, mask);
g.drawImage(print, 240, 0); damage(g, 240, 0, W, H, Math.round(t * 24), .6);
```
（`?scene=frames.oneColour` 呈现此示例。）
