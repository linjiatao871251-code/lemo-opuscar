# 科幻情景喜剧卡通 — 我们的示范

众多例子中的一个。请勿重复使用其故事、弧线、镜头、道具或时间安排。

示范：*咖啡运行* (57.5 s) · `scifi-toon.mp4` · 来源在 [`demo/`](demo/)


原始简介：这种风格的 30-60 秒影片；导演决定前提、笑话、演员、镜头、时间安排、音乐和声音，并在没有征求批准的情况下交付。

<a id="story--structure"></a>
## 故事与结构

实验室没有咖啡了。一位穿着浴袍的疲惫天才穿越宇宙，与他紧张的伙伴加里一起补充能量；每个宇宙都有更糟糕的咖啡；他们带回来的东西是不含咖啡因的。微小而平凡的目标+大得荒谬的科幻手段。

我们概述了将其他主题变成差事的方法（仅供参考）：
- 产品发布 → 天才跨越维度寻找产品的工作版本；每个宇宙都有一个更糟糕的宇宙；他们带回来的东西有一个转折。
- 课程/讲解员 → 助手问一个简单的问题；从字面上看，每个宇宙都是一个错误的答案；最后一个是正确的，但有代价。
- 假期/活动→“我们没有X参加聚会”→越来越错误的X宇宙。

**示范的拍片（57.5秒）：**
1. **冷开（8-12秒）**：平凡的问题，未显示（空锅，最后一滴）。助手解释过多，天才一句话打断了他。还没有音乐，也没有标题。
2. **Portal + title slam (2–3 s)** 音乐上的悲观音乐。
3. **跳跃1（6-8秒）**，果冻世界：慢：到达，尝试，揭示插入特写中的错误，**剪切音乐**，反应镜头，一字拒绝。
4. **跳跃 2 (6–8 s)**，杯子世界：更快更差；助手失去了它；同样的拒绝词。
5. **蒙太奇（3 × 1 s）**：牙齿、鸽子和克隆世界；每个宇宙一秒，每次都是同一个词，切合节拍。
6. **中断（4-5秒）**：宇宙“异常正常”。模式被打破；平静就是个笑话。
7. **Home（12–16秒）**：解脱→逆转（无咖啡因）→**2+秒的死寂**→天才用一行字揭示了他的价值体系→按钮。
8. **按钮**：回调到开头行，以便故事循环。
9. **端卡（4–5秒）.**

<a id="shots"></a>
## 镜头

|打|摄影机|
|---|---|
|冷开|空咖啡壶的静态插入特写，缓慢推动|
|对话|表现媒介二-镜头； **中断时硬切至特写**|
|揭露荒谬|插入极端特写，然后切到反应特写|
|恐慌|紧致特写，关键词上有简短的摄影机抖动|
|跳跃|“冲”进传送门 → 全屏漩涡擦拭 → 下一个世界从漩涡中打开|
|剪辑|每个世界都有相同的框架（左为二人组，右为生物），因此只有世界发生变化|
|冷冷的沉默|两个镜头的支座，非常缓慢地推入，除了沸腾之外没有任何移动|
|按钮/结束|宽镜头，因此门户和两个角色都在框架内； 片尾卡如下|

<a id="score-structure"></a>
## 配乐结构

- 120 BPM，因此可以快速切换到半秒节拍。 Theremin 主导模拟低音、十六分音符方形琶音和复古鼓机。 D 小调主旋律，半音阶 D–A–B♭–A–E–F–E–E♭–D。
- **每个宇宙一个主题**，每个单独的提示，其**的第一个节拍是剪辑**：有弹性的大号+摇摆的主音+幻灯片哨子（果冻），带有振动的拉丝摇摆爵士乐（杯子），在四层地板脉冲上的1秒刺痛（蒙太奇），卡普拉斯的电梯波萨——强尼龙吉他（“正常”世界），温暖的罗兹+特雷门“啊”（舒缓），上升的颤音弦（恐慌）。
- 沉默：音乐（和混响尾音）硬切在果冻揭示插入物上，并在“脱咖啡因”之后有 2 秒以上的冷停顿；只剩下荧光嗡嗡声+时钟滴答声。
- 拟音使用：传送门 open/hum/close、每次擦拭时旋转呼啸、吐出和着陆时的 pop/boing、用于粘液生物的 glorp/squish/blink、吸管吸食、咬牙切齿、鸽子咕咕声、店铃、气泡声、闪烁“blip”、远程点击蜂鸣声。
- 声音：面无表情的天才 = Kokoro `am_onyx`，速度 0.82–0.9，光饱和度 + 180 Hz 凹凸； sidekick = Kokoro `am_eric`，速度1.1–1.15，存在感提升；一个小生物 = Kokoro `af_sky` 一两个词的音高 +7 个半音。通过生成测试线并测量中值 f0/音高方差来进行投射。对话时音乐降低约−7 dB；主控-14 LUFS。
- 最后的低音音符位于 D2 上：持续的 D1 (37 Hz) 仅在笔记本电脑扬声器上发出隆隆声。

<a id="palette--props"></a>
## 调色板和道具

- 线条：`#1b1422`，7 px 角色和道具。
- 家庭实验室：鼠尾草绿 `#a7c3b1`、橄榄色地板、温暖的木材、一种橙色调。
- 果冻世界：洋红色天空带`#ff4f9a→#ff9bcb`、石灰果冻`#b8f03c`、青色`#52e0e0`。
- 马克杯世界：橙色天空`#ff7a2f→#ffb862`，青色山丘`#2b9c98`，奶油色。
- 牙齿世界：红色`#c3122f`，牙龈粉色`#ff8fa6`，牙齿白色。鸽子世界：石板蓝`#5f78a8`、灰色。克隆世界：倒紫色`#3b1f66`+黄色`#e8d84a`。
- “正常”世界：故意平淡的米色`#f1e3c6`和棕色。
- 演员：浴衣天才+毛绒拖鞋+护目镜；戴着自行车头盔+巨大圆框眼镜的搭档加里。
- 传送门：垂直椭圆形（x 尺度~0.74），块状粘性边缘 `#3fd93a`，轮廓为 7-8 像素，5 个螺旋臂交替 `#b8ff5a`/`#21b33c` 旋转 **on 一个**，一个苍白的核心，绕轨道运行的火花，从底部，打开时场景上方有一个平坦的绿色水彩晕染； ~12% 过冲，后缓 0.32 秒。用遥控器打开。
- 宇宙读数：VT323 标签左上角，输入，按世界着色。
- 咖啡：拿铁艺术心形，滴在边缘和蒸汽（一个普通的棕色斑点，读作土豆）。

<a id="titles--end-card"></a>
## 标题 & 片尾卡

- 标题：1950 年代原子时代的电视标题：奶油色粗大的大写字母（Bungee），带有硬洋红色偏移阴影和浓密的墨水轮廓，被倾斜的青色轨道环包裹，周围飞舞着咖啡豆和一些闪烁的四点星星；在音乐的节奏中以 12 fps 的速度突然出现。
- 片尾卡：深紫色，缓慢变暗的门户，标题，终端字体中的风格名称，“LemoLab × Claude Opus 5.5”，制作人员；门户网站中的一个小小的片尾恶作剧。此签核仅属于本库的示范；用户的影片没有 LemoLab 积分，也没有该卡的副本。

<a id="build-notes"></a>
## 构建笔记

```
styles/scifi-toon/demo/
  toon.js     vector engine: matrix stack, screen-space boil, constant line width, flat shading
  chars.js    the cast (parametric eyes, mouths, hands, noodle limbs) + props
  worlds.js   one function per universe + creatures + the portal
  story.js    single source of truth: VO start times, shots, wipes, tags, key beats, music cues
  main.js     acting per shot, cameras, wipes, tags, subtitles, title, end card, window.EV
  lines.json  script (tts text, subtitle text, speaker, voice, pitch, cut)
  voice.py    per-character processing + lip-sync envelopes   asr.py   padded whisper check
  music/score.py  synthesized score from the cue list        mix.py   foley + voices + ducking + ambience
  srt.mjs  build.sh  sheet.sh (contact sheets)  strip.sh (consecutive-frame strips)  levels.py (stem meters)
```

1. 写入创作方案。通过生成测试线并测量中值 f0/音高方差来投射声音。
2. `core/tts/tts.py lines.json out/raw` → `voice.py` → `asr.py` 直到每条线都通过。
3. 将 VO 时间、镜头和提示放入 `story.js`； `main.js` 中的块镜头；使用`sheet.sh`（1 frame/s）和`strip.sh`（连续帧）进行审查，至少两轮。
4. `core/render/events.mjs` → `music/score.py` → `mix.py`（检查 `levels.py` 和频谱图）。
5. `sh demo/build.sh` 再现一切：TTS → 声音 → 事件 → 配乐 → 混合 → SRT → 渲染（1380 帧 ≈ 15 秒，4 个工作人员）→ 在 −14 LUFS 进行复用。在 M 系列 Mac 上完全重建约 1 分钟。

与示范相关的陷阱：
- Kokoro + 耳语：名字“Pim”低沉的声音读作“Pam”； “加里”工作了。 “b-broken”读作“被打破”； “buh，buh-broken”，“Wh，wh，why”有效。 “无咖啡因”出现了“D-cuff”； “dee-caf”是可靠的。
- 一个有弹性的门户（lib `spring`）超过了~135%并吞噬了演员。
- 商店柜台后面的生物消失了；他们被感动了，所以脸部和上半身都露出来了。
