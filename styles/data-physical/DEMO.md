# 数据物理化——我们的示范

众多例子中的一个。请勿重复使用其故事、弧线、镜头、道具或时间安排。

示范: *两个螺旋*《旋转螺旋》 (39.4 s) · `data-physical.mp4` · 来源在 [`demo/`](demo/)

十二年的全球风能和太阳能容量（IRENA 2026，来自我们的数据世界，CC BY 4.0），在胡桃木表盘上构建为两个螺旋形的真实板：一块板的容量为 10 GW，铝板用于太阳能，青色丙烯酸用于风能，每 100 GW 一块黄铜板。中文屏幕，英文旁白，双语字幕（中文上行，英文下行）。这是根据已发布数据制作的非官方影片； IRENA 和我们的数据世界并未制定或认可它。

<a id="story--structure"></a>
## 故事与结构

梗概：2014 年，全球风能发电量几乎是太阳能发电量的两倍； 2021年太阳能超过风能；到 2025 年，该比例将相反（太阳能 = 风能 × 1.86）。

弧线：配对（2014年，风能和太阳能并排，保持，然后判决×1.95）→规则（一块板和一块黄铜板的宏观）→增长（2015-2020对在摄影机沿着螺旋轨道时聚集）→转弯（2020和2021对保持静止，有四个读数，吸出，然后“2021·太阳能超过风”）→高潮（2025 年：去年的水平级联进入，然后 52 个新板被一一送入，同时计数器滚动到 2,396.7 GW）→ 揭晓（起重机拉回接近俯视图：两个螺旋和镶嵌的刻度变成一个表盘）→ 结局（刻有 ×1.86 的黄铜圆盘落到中心；片尾卡）。

风格特有表现手法花：规则的*单位特写*； *十年来的配对攀登*； *2025 年的饲料*； *安装图表*作为签名拉回； *最后一个对象*代表最终数字。每个数字及其来源都在[`demo/FACTS.md`](demo/FACTS.md)中。

## 配乐结构

96 BPM，4/4，D 大调；每小节一个和弦：Dadd9 – Dadd9 – Bm – Gmaj7|D – A/C♯ – Bm – G|华硕（第 8 栏，缩短）|D – Bm – G|A-Gmaj7|D – D。

|部分|时间|调色板|笔记|
|---|---|---|---|
|风引|0–10|玻璃竖琴 + 竖琴图案 (A5 F♯5 E5 D5…)、合成器垫、弓形颤音琴|疏;板片本身的滴答声和铜管音符承载着节奏|
|生长|10–20|马林巴八度琶音，四度脉冲低音（2nd/3rd 和声）|每对的级联都是蜱虫和钟琴/玻璃音符攀登 D 五声音阶的琶音（每 100 GW 一个音符）|
|交叉|20–21.875|A 上的定音鼓心跳，喇叭 A3|吸出 21.5–21.875（音乐和拟音 −30 dB）|
|转动|21.875|冲孔器 (60–120 Hz) + 低音鼓 + 定音鼓 D3 + 圆号 D–F♯–A + 长号 D2 + 钟琴 F♯6 + 金属环|第二响亮的时刻|
|2025年|22.5–30|马林巴第 16 音，脉冲第 8 音，在馈线上有一条钟琴线 D6–E6–F♯6–A6–B6–A6； 52个金属蜱虫；当最后一个板落地时，电颤琴和弦 + 定音鼓 (29.2)|最密集的伸展|
|拨号|30–33.75|圆号D3/A3/F♯4和大提琴D3在起重机下，马林巴回到八度|吸出 33.75–34.375|
|冰球|34.375|冲床+低音鼓+大卡萨+定音鼓D3+管铃D5/A4+金属环；冰球沉降的五个小滴答声|影片最响亮的时刻|
|结尾|34.4–39.4|竖琴琶音 D4…D6，弓弦颤音器 D5/A4|褪色|

混音 (`demo/mix.py`)：分轨音频设置为针对语音的有效 RMS（音乐 −10.9 dB，脉冲 −12.2 dB，拟音 −8.6 dB，命中 −2.3 dB，录音室空气床远低于），音乐在语音下降低约 4 dB；仅对音乐、脉冲、拟音和床进行总线压缩； 36 Hz 高通（44 Hz，点击时为 4 阶）和除语音外的所有内容均低于 62 Hz 的 −5 dB 架；主控至−14.4 LUFS，并在−4.6 dBTP处使用4倍过采样真实峰值限制器，然后是`mux.sh` (−14 LUFS)。 影片集成测量为 −13.8 LUFS，LRA 6.6 LU。

<a id="palette--props"></a>
## 调色板和道具

- 用雾扫#C4BEB4；胡桃木贴面表盘（r 3.35，厚 0.11），铝制边缘，镶嵌 #EFE4CF：2° 刻度环，两条螺旋路径（长划线代表太阳能，短划线代表风），JetBrains Mono 年份。
- 太阳能：铝板#C8CCD1，金属度1，粗糙度0.27；风：丙烯酸#9FD3D6，透射率0.72，清漆，青色衰减；黄铜#D2B07A 每十块板中都有。板材0.50×0.42，厚0.0125（10GW）；太阳环 r 2.25–2.58，风环内侧 0.6，每年 27.6°。
- 灯光：暖键#FFF1DC，从左侧~35°，4096 阴影贴图；右后和右前的炫酷轮圈#B9D2FF / #C6DBFF； HDRI `photo_studio_loft_hall` 反射率为 0.8。
- 圆盘：黄铜，r 0.64，刻有（深色古铜色）“2025·×1.86·太阳能 ÷ 风电”，带有刻度环。
- 类型：Inter 200/300 用于数字，Noto Sans SC 500 用于标签、判决和字幕，JetBrains Mono 用于年份和单位，Noto Serif SC 600 用于标题。墨水#1C1D20，重音#D4521C。
- 旁白：Kokoro `af_heart`，速度0.95。

## 端卡

转动转盘左第三个：扭转（Noto Serif SC），*两个螺旋*，一般为`DATA PHYSICALIZATION · 数据实物化`，`LemoLab × Claude Opus 5.5`；其上方是重音线，其引导线指向冰球；数据源从起重机开始就位于右上角。 4.6 秒。 “LemoLab × Claude Opus 5.5”签名仅属于该库的示范；用户的影片没有 LemoLab 积分，也没有该卡的副本。

## 构建笔记

```
demo/
  build.sh          one command: fonts (first run) → voice → speech check → cues → events → picture → mix → master → .srt → checks → poster
  index.html        WebGL canvas + 2D overlay canvas, fonts.css
  timeline.js       single source: BPM grid, build times, holds, verdicts, suck-outs, narration + subtitles, every on-screen string (LABELS)
  data.js           the twelve years of both series (IRENA 2026 via OWID) and the unit rule
  set.js            the physical set (lights, walnut dial + inlay, instanced plates per material, the puck), the landing schedule, EVENTS
  film.js           camera keys, reading kit (pairLabels, verdict, counter), subtitles, end card, TEXTS (readcheck), SUBCHECK, EV
  mix.py            score, material foley, voice, suck-outs, mix and master → out/mix.wav, out/stems/
  tools/            export.mjs (voice lines, timeline.json, cues), fonts.mjs (OFL subsets), srt.mjs, subcheck.mjs, holdcheck.py
  data/             the downloaded CSVs and metadata
  FACTS.md, CREDITS, stills/styleframe.jpg
```

- 需要 `setup.sh deps voice`（Kokoro 和faster-whisper；耳语 `small.en` 模型在第一次检查时下载）。 `build.sh` 仅在丢失时获取 git 不包含的内容：工作室 HDRI（`sh tools/fetch.sh hdri`，12 MB）、Kokoro 模型（`fetch.sh voice`）、采样音色库 `vsco2ce`、`vcsl`、当 `fonts.css` 中命名的 `.woff2` 丢失时，`freepats`（`fetch.sh instruments <lib>`，总共约 1 GB）以及字体子集（来自 Google Fonts CSS2 API 的 `tools/fonts.mjs`，OFL：Noto Sans SC、Noto Serif SC、Inter、JetBrains Mono）。胡桃木贴面纹理位于 git (`core/assets/polyhaven/`) 中，数据 CSV 位于 `demo/data/` 中。
- `sh demo/build.sh` 在 Apple 芯片上大约需要 7 分钟；图片（945 帧，2× 超采样，丙烯酸传输）大约 55 秒，有 3 名工人，其余大部分进行语音检查。
- 检查它运行：`asr_check.py`（small.en，7/7），带有真实字体的字幕单行宽度（最宽836像素对1100像素），`readcheck.mjs`（全部通过），`holdcheck.py`（2014年对举行2.77秒， 2020/2021 在判决前等待了 2.67 秒）。
- 示范特定的陷阱：铝和透明亚克力首先被视为相同的白板，因此亚克力具有青色色调和衰减，而铝具有完整的金属感；长长的温暖阴影将远处的铝色变成棕色，直到添加了两个冷色边缘； 2014和2020/2021读数柱与判定板碰撞，直到它们保持在y = 430以下； 2025 堆栈位于字幕条后面，直到起重机的目标落到顶部以下；对于此摄影机，俯视圆盘雕刻仅在偏航 π/2 + 0.30 时才能垂直读取。
