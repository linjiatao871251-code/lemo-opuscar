# 丝网印刷旅行海报 — 我们的示范

众多例子中的一个。请勿重复使用其故事、弧线、镜头、道具或时间安排。

示范：*三条路径* (38.4 s) · `silkscreen-poster.mp4` · 来源在 [`demo/`](demo/)


<a id="story--structure"></a>
## 故事与结构

虚构公园的步道指南：打印了三张步道海报，一张比上一张更快，第三张是在一个长镜头中攀登的，所有三张海报最终都出现在游客中心的墙上。没有旁白。

这是 STYLE.md §11（步道/景点指南）的第一个用例。 镜头结构：标题横幅拉动→海报1逐层打印→海报2八分音符打印→最后一张海报一次爬上→拉回墙壁。信息顺序：公园名称→场景→步道名称→难度→距离→时间→攀登→页脚。持有：标题 3.2 秒；名称 ≥ chars/12+1 秒；统计行在最后一项之后 ≥ 2.2–3.0 秒； 3 条路线 30–40 秒。

STYLE.md §11 中的其他用例使用相同的引擎：场景只是平面列表，带模板采用任意 1-4 个事实，而 `swap` 在另一个调色板中重新绘制整个海报。

**风格特有表现手法如何提供信息**（不是故事）：
- *一墨，一拍*：每次拉动都是一次音乐打击，因此眼睛会按顺序穿过各层，最后打印事实，这正是阅读它们的时间。
- *分流墨斗*：一次拉动多种墨水。它打开了影片，因为一笔就使框架充满了颜色。
- *调色板重新墨水*：整个海报再次拉入下一个时间调色板。在示范中，这是数据点“7 小时”：当摄影机攀升时，这一天过去了。
- *套准滑→卡扣*：在爬升过程中，各层松动（白色间隙、纸张厚度的阴影），然后一击即可夹紧套准。这是影片唯一一次在最重要的事实面前暂停。
- *纸张作为一种颜色*：瀑布只是未印刷的纸张，是纸张上最亮的东西。
- *作为印刷层的轨迹*：路线是太阳墨水中的一条虚线，摄影机跟随它逐段标记。

统一转场语法：刮刀层层变化；海报随着前景树木的变化而变化； 影片以刮刀拉动端卡墨水结束。没有溶解，也没有裸露。

示范动作编号：八分音符上每个信息频段项目 0.18 秒；重音墨水 `sub: 1`（晚半拍）；屏幕升降0.4秒；调色板在 0.35 秒内以 -12° 交换刀片；爬升视差`(camTopY − camY) × (depth − 1) × 0.42`，每个支线向侧面滑动（高斯凹凸，190 u×深度）；纸张间隙 3 u 和厚度阴影 9 u 为 28%，按“松散度”缩放，配准快照上为零。钩车横滚-1.7°。

<a id="score-structure"></a>
## 配乐结构

- **音乐**：美国户外民谣，100 BPM，D大调，开放式D吉他扫弦（物理模型），幻灯片吉他（numpy），VCSL口琴，箱鼓底鼓，刷子，立式贝斯。 **E每次拉动是一把扫弦**，随着层越来越近，和弦爬升D – D/F# – G – A。海报 2 双倍到八分音符（加速）。攀爬过程中会逐个搭建仪器。注册快照是影片中最响亮的悲观声音。
- **Foley（由材料制成）**：网格上的刮墨刀（来自网格的 220–280 Hz 振幅颗粒的带通噪声；更快的拉动 = 更亮）、湿墨“静噪”（正弦下降加上粘性噪声）、铝屏幕咔哒声加上铰链吱吱声、用于统计的纸印章、用于轨迹破折号的 16 分音符刻度、滑动层的纸张嘶嘶声，以及木材和金属的定位夹。
- **环境**：工作室房间色调；海报 1 中的湖面在屏幕升起时淡入（印刷品“醒来”）；瀑布（J 切提前 0.9 秒）；山风（J-切入寂静，L-切入墙壁）；游客中心有杂音、门声、脚步声。
- **沉默**：18.0–19.2 s（音乐关闭；瀑布尾部衰减到约−59 dBFS；长距离向上滑动后的第一个声音）和23.4–24.0 s（仅风；之后的第一个声音是钳位加上整个乐队）。
- 拟音下的音乐降低 2.5 dB。大师：−14 LUFS。

<a id="palette--props"></a>
## 调色板和道具

- **调色板规则**：每张海报一个调色板，6种墨水：`sky1`（浅色天空）、`sky2`（深空/波段）、`far`、`mid`、`near` （最暗，也是信息带），`sun`（一个明亮的口音：阳光、小径、难度、攀登）。可选的 `glow` 是山的发光面。给定的海报应使用 ≤ 6 个。 示范调色板是：
  - 曙光`#F6CD98 #EE9A73 #9A7FA8 #3E7079 #1E3B3F #FBE6B4`
  - 中午 `#E4EEDC #86BCD0 #C2AE92 #4C8753 #1D4331 #F2C14A`
  - 金色 `#F7D787 #E9A94F #A57C68 #5E7A45 #2B3A28 #FFF1C4`
  - 黄昏 `#F4B461 #D8613F #7C3E5F #43325A #1B1B2F #FBE3A6`
  - 纸张 `#F2E8D2`。标题横幅 `#F7C66B #E4683F #2F6F73 #1C2A33`。
- **对比度是自动的**：通过 WCAG 与下面的油墨对比 (`pickInk`) 选择文本油墨。夜间调色板不会使标题消失。
- **形状**：山脉是中点位移的山脊，具有锯齿状的亮面；松树是一排下垂的轮廓加上一根短树干；水是一个扁平的物体，带有水平的闪光条；森林是坚实的基础上成排的松树。一切都用硬边绘制。
- **海报模板**（单位1000×1500）：纸边框26u；艺术区 y = 1140；场景向上移动 50 u，因此裁剪了一点天空以为信息带腾出空间。带子（y 1148–1474，`near` 墨水）包含轨迹名称（Big Shoulders Display 900，最大 122 u，自动调整）、`sun` 中的编号 `01`–`04`、6 u `sun` 规则和统计数据行：标签 34–38 u（服装 600，字母间隔），值 48–68 u（Big Shoulders 800）。列的大小根据内容而定。在比例为 0.49 的墙上，标签约为 18 像素，值约为 31 像素。
- **标头**：在 62 u 处追踪到的公园名称，打印在天空中。
- **纹理预算**：纸片每纹素0.6 u，斑驳倍数为55％，针孔为75％，然后是ffmpeg颗粒3。超过这个开始读取为risograph。

<a id="titles--text"></a>
## 标题和文字

没有旁白，也没有字幕：海报文字*就是*信息。标题卡是一个打印的 4:1 横幅（1800×440 u，标题分成两条平衡线），框架填充宽度（约 5 % 边距，约 40 % 框架高度），成为最终墙的标题（悬挂在 1150 像素宽，因此海报保持 ≥30 像素值）。 示范中使用的读取规则：每个文本在 **最后的** 项落地后保持 ≥ chars/12 + 1 s（最少 1.5 s）。时间线根据 `content.json` 计算此值并向上舍入到节拍。

<a id="end-card"></a>
## 端卡

片尾卡作为最后一张风景迷你海报分两次打印：一个用于艺术的分体喷泉拉（天空带、太阳环、山脊、轨迹破折号、标题），然后是一个用于信息带的 `near` 拉（风格名称、`Lemo-Opuscar`、`LemoLab × Claude Opus 5.5`、字体和样本来源）。 “LemoLab × Claude Opus 5.5”签名仅属于该库的示范；用户的影片没有 LemoLab 积分，也没有该卡的副本。

<a id="build-notes"></a>
## 构建笔记

`sh styles/silkscreen-poster/demo/build.sh` 重建一切：
1. `tools/timeline.mjs` 打印源自 `content.json` 的时间线。
2. `core/render/events.mjs` → `events.json`（每次拉、举、带、名称、项目、擦除、交换、部分、静音、咔哒声）。
3. `music/compose.py` 读取为 `events.json` → `score.wav` 加分轨音频。
4. `mix.py` → `mix.wav`（氛围、拟音、音量闪避、静音窗）。
5. `tools/cuecheck.py` 根据事件检查混合起始点：中位误差 4 ms； 30/33 1 帧内。其余的是重叠事件和缓慢的口琴攻击。
6. 渲染（`--workers 2`，如果您的机器有渲染限制器，则通过渲染限制器）→ `mux.sh … 24 3`。

文件：`engine/silk.js`（打印引擎）、`engine/scenes.js`（5 个内置场景）、`engine/poster.js`（模板、横幅、对比度）、`film.js`（时间轴和镜头）、`mix.py`、`music/compose.py`。每帧大约 0.1 秒；完整渲染需要不到一分钟的时间。

<a id="pitfalls-we-hit"></a>
### 我们遇到的陷阱

- **基于笔画的边缘效果在联合路径上绘制内部线条。** 绘制为松树联合的森林显示了每棵树的轮廓。仅使用填充进行光泽和陷印：填充形状，然后在剪辑内再次移动填充。
- **屏幕阴影使整个打印变暗。** 框架的阴影必须是环形（偶数-奇数），而不是完整的矩形，否则网格下的所有内容看起来都是浑浊的。
- **花岗岩上的蓝色阴影面读作水。** 将阴影平面保留在 `near` 中，并将它们放在瀑布旁边的内表面上。
- **特写镜头上的厚刮刀将框架分成“两张图片”。** 倾斜刀片，隐藏大部分手柄，并保持几何形状连续。
- **锯齿状三角形墨珠读取为纸张边缘。** 墨珠需要圆度：亮半面、暗底面、高光和股线。
- **视差单独读作“山在移动”。** 在图层松散时显示纸张间隙和厚度阴影，并通过声音将它们捕捉到零。
- **Night 调色板隐藏了标题和标签。** 通过对比选择文本墨水 (`pickInk`)，而不是通过固定键。
- **湿光泽梯度卡在拉动结束时**（条件`p < 1.02`永远保持正确）。随时间淡出。
- **树擦拭覆盖框架0.4 s**（深色空白）。将剪影置于切换时间的中心，以便全覆盖持续约 1 帧。
- 在这些读取时间中，有 4 条路线运行时间约为 45 秒。有关如何压缩，请参阅下面的“40 秒内的四条路径”。
- **A 7:1标题横幅是16:9帧**中的一条条子（大约1/5的高度，很多空桌子）。使横幅大约为 4:1，以便它可以填充宽度和大约 40% 的高度。
- **桌子上的随机彩色点读作五彩纸屑或占位符。** 构建一个真正的工作台：木板、纹理、结、一些大的静音墨渍和撕破的胶带。
- **信息带上的特写镜头必须使整个带保持在框架** 中，侧边距≥5%（对于 1000 u 海报，z ≤ 1.75）。正在打印的纸张上的特写镜头必须将纸张的边缘保持在框架内，否则观看者只能看到单调的颜色。

<a id="engine-reference"></a>
## 发动机参考

`engine/silk.js` 以这种风格打印 **任何形状**：它只需要当前变换使用的任何单位的 `Path2D` 。

|功能|它的作用|
|---|---|
|`makeTextures(paperHex, seed)`|纸、斑点和针孔瓷砖（一次）|
|`paperSheet(ctx, T, x, y, w, h)`|纸材|
|`ink(ctx, part, o)`|一层油墨。 `part = { path, knock?, paint? }`（`knock` = 打孔，`paint(ctx)` = 自定义填充，例如文本）。 `o = { color, reg:[dx,dy], clip, sheen, trap }`|
|`wipeRegion(box, dir, p, seed)` / `wipeFront(...)`|粗糙的吸水扒前端作为剪切路径，以及刀片所在的位置|
|`squeegee(ctx, a, b, lead, o)`|刀片从`a`到`b`沿`lead`移动； `o.beads=[{t0,t1,color}]`（分体喷泉）、`roll`、`handle` 0–1、`scale`|
|`screenFrame(ctx, box, o)`|带网、乳液和胶带的铰链屏； `lift` 0–1|
|`inkFinish(ctx, T, x, y, w, h)`|纸张上有斑点和针孔|
|`bandSteps(x, w, y0, y1, n)`|阶梯色带（渐变替代品）|
|`ridgeLine`、`polyPath`、`circlePath`、`ringPath`|形状助手|

`engine/poster.js`：`buildPoster(content, trail, i, n)`、`drawPoster(ctx, P, { pal, T, prog, off, reg, sep, swap, items, … })`、`drawBanner`、`pickInk`。 `engine/scenes.js`：`buildScene('lake'|'waterfall'|'ridge'|'forest'|'coast')` 返回可以重新排序或扩展的平面。

最小的例子：带有光标尾部的暖橙色 `#D97757` 四点火花，用两种墨水打印并从天空中敲出，然后由刮刀拉入：
```js
import { makeTextures, paperSheet, ink, wipeRegion, wipeFront, squeegee, inkFinish, polyPath, rectPath, circlePath } from './engine/silk.js';
const T = makeTextures('#F2E8D2');
paperSheet(ctx, T, 0, 0, 800, 600);
const spark = polyPath([[400,180],[430,270],[520,300],[430,330],[400,420],[370,330],[280,300],[370,270]]);
const tail = rectPath(540, 285, 160, 30);
const p = 0.7;                                                    // 70 % of the pull done
const clip = wipeRegion([0, 0, 800, 600], 'right', p, 3);
ink(ctx, { path: rectPath(0, 0, 800, 600), knock: circlePath(400, 300, 150) }, { color: '#1C2A33', clip, sheen: 1 });   // sky with a knocked-out halo
ink(ctx, { path: spark }, { color: '#D97757', reg: [2, -1], clip, sheen: 1, trap: 1 });
ink(ctx, { path: tail }, { color: '#D97757', reg: [2, -1], clip, sheen: 1 });
const x = wipeFront([0, 0, 800, 600], 'right', p);
squeegee(ctx, [x + 10, -20], [x + 10, 620], [1, 0], { color: '#D97757', roll: x / 30 });
inkFinish(ctx, T, 0, 0, 800, 600);
```
单色海报：保留一个调色板键（通常为 `sun`）作为唯一颜色，并将其他墨水设置为一种色调。 `pickInk` 保持文本清晰易读。

<a id="contentjson-fields"></a>
## content.json 字段

所有文字、数据和颜色均来自`demo/content.json`； `film.js` 中没有副本。

|场地|类型|范围|如果超出范围|
|---|---|---|---|
|`park`|细绳|≤ 22 个字符|标题的字母间距为 62 u；较长的名称超出了天空的宽度（缩短或减少跟踪）|
|`title`|细绳|≤ 34 个字符|自动适应横幅上的 132 → 60 u； 60 u 以下，它会变得太小而无法阅读|
|`footer`|细绳|≤ 45 个字符|横幅条中的一行；墙的支撑力随着阅读时间的增加而增长|
|`trails[]`|大批|**1–4**|1 = 仅按下（不爬升）； 2 = 按下 + 爬升； 3 = 按下、快速、爬升； 4 = 按下、快速、快速、爬升（大约 45 秒，见下文）。以上4，墙上的海报变得太小看不清|
|`trails[].name`|细绳|≤ 22 个字符|自动适应 122 → 60 u|
|`trails[].difficulty`|`easy` \|`moderate` \|`hard` \|`expert`|—|未知值显示 1 个实心三角形|
|`trails[].distance`|数字|任何|打印为 `3.2 KM`（单位来自 `units.distance`）|
|`trails[].time`|细绳|≤ 7 个字符（`1 h`、`45 min`）|列变宽并且所有值一起缩小（最小 48 u）|
|`trails[].elevation`|数字 \|无效的|null 隐藏 CLIMB 列|在 `sun` 墨水中显示为 `↑1,100 M`|
|`trails[].scene`|`lake` \|`waterfall` \|`ridge` \|`forest` \|`coast`|内置|未知 → `lake`|
|`trails[].time_of_day`|键入 `palette`|`dawn`、`noon`、`golden`、`dusk`、`night`|缺失 → `noon`。攀爬路线从上一条路线的调色板通过 `golden` 重新绘制到这条路线|
|`palette.<time>`|`{sky1, sky2, far, mid, near, sun, glow?}`|十六进制|自动检查文本对比度|
|`palette.paper`、`palette.wall`、`banner_time`|十六进制/对象/密钥|—|—|

**步骤**：编辑`content.json` → `sh demo/build.sh`。没有 TTS；音乐和混音从 `events.json` 重新计时。要预览另一个文件而不覆盖：`node core/render/still.mjs styles/silkscreen-poster/demo 30 --q content=content_alt.json`。

**40 秒内有四条踪迹**：阅读规则使每张中间海报长约 6 秒。选项，按优先顺序排列：
1. 将两张中间的海报 **并排打印在同一张桌子上的同一张拉片** 上（一个快速部分，两个带，一起阅读）。
2. 对于中间的海报，将每个项目的邮票间距从八分之一减少到十六分之一。
3. 跳过中间海报上的乐队特写，让它们在最后一面墙上朗读（将墙保持时间延长 2 秒）。

`content_alt.json`（4条步道，dawn/golden/noon/night，一个新的公园、墙壁和横幅调色板）是经过测试的示例。其剧照位于`demo/stills/alt_*.jpg`。

最少内容：
```json
{ "park": "Pine Lake", "title": "One Walk at Pine Lake", "footer": "Open dawn to dusk",
  "units": { "distance": "km", "elevation": "m" }, "banner_time": "dawn",
  "trails": [ { "name": "Shore Path", "difficulty": "easy", "distance": 2, "time": "40 min",
```
